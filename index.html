01

Kabiyè–Èʋɛ NLP Toolkit

Traduction automatique FR ↔ Éwé · NLP pour les langues togolaises

Toolkit open-source de traitement automatique des langues togolaises : traduction automatique français-éwé via un modèle NLLB-200 fine-tuné par LoRA, corpus parallèle de 65 640 paires, API REST, CLI et démo interactive.

  • → Modèle NLLB-200 (600M) fine-tuné par LoRA, publié sur HuggingFace
  • → Corpus parallèle FR ↔ Éwé : 65 640 paires (Bible 1913 + OPUS NLLB)
  • → FR → Éwé : BLEU 18,71 et chrF++ 41,83 (+7,3 pts vs zero-shot)
  • → Déploiement : API FastAPI, CLI batch, démo Gradio sur HuggingFace Spaces
